# Referanstaki mobil tek sayfalık dizin ilan stilini yeniden oluştur: koyu arka plan, turuncu...

Referanstaki mobil tek sayfalık dizin/ilan stilini yeniden oluştur: koyu arka plan, turuncu vurgu, üstte dikkat çekici reklam/uyarı alanı ve altında fotoğraf kolajlı ilan kartları. Türkçe arayüz kullan. İsim, kısa açıklama, fotoğraflar, telefon ve WhatsApp bağlantıları kolayca özelleştirilebilir olsun. Yalnızca kullanıcı tarafından sağlanan veya güvenli yer tutucu görseller kullan; yetişkin içerikli görseller kullanma. Mobilde referanstaki görünüme çok yakın, masaüstünde de duyarlı olsun.
